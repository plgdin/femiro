# Femiro Storefront

A luxury, high-end storefront built for Femiro Designs.

## Features
- **Curated Collections**: Shop Kurtis, Co-ords, Salwar Sets, Trousers & New Arrivals.
- **Dynamic Filtering & Sorting**: Instant category filtering and price/alphabetical sorting.
- **Header Search Bar**: Expanding search bar with live dropdown search popover.
- **Cart & Wishlist**: Table cart view, gift notes, coupon application, and toast notifications.
- **Admin CMS**: Product catalog management and order tracking.

## Tech Stack
- React + TypeScript
- Vite
- Supabase Integration
- Lucide React Icons
